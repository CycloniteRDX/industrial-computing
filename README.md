# Industrial Informatics

Coursework repository for the Industrial Informatics course.

## Topics

The course covers topics such as:

* Python
* Object-oriented programming
* Qt / Qt Designer
* SCADA development
* OPC
* Databases

## Repository purpose

This repository contains exercises, examples, classwork and projects developed during the course.

The repository is intended to preserve the evolution of the exercises using Git rather than keeping multiple copies such as `exercise_v1.py`, `exercise_v2.py`, etc.

## Structure

The repository will be organized progressively as new topics are introduced during the course.

## Git workflow

The `main` branch contains the normal course work.

Changes are committed when they represent a meaningful and working step in the evolution of an exercise or project.

Temporary branches may be introduced later for experiments, larger features or refactors.
